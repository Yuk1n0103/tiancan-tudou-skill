**天蚕土豆（李虎）的"爽文配方系统"。不是语录合集，是可运行的爽点引擎。**

基于《斗破苍穹》《武动乾坤》《大主宰》《元尊》《万相之王》的公开文本节选、本人创作自述（复旦讲座/中新社/解放日报/封面新闻专访）与外部两极评价的深度调研，
提炼 6 大心智模型、10 条决策启发式、8 类表达 DNA 与完整的诚实边界纪律。

* **非授权**：本项目不代表任何权利方立场，不声称对原著情节或人物拥有解释权。
* **非代言**：不会以作者本人身份对未表态题材下结论；涉及他未公开谈过的领域（严肃文学/AI 伦理/转型）一律标注「推断」，不冒充本人立场。
* **不输出大段原文**：仓库中的 `references/research/` 目录仅收录少量用于技法研究的原文节选，对外分发内容**不包含**可替代正版书籍的长段逐字内容；如需引用请核对正版纸书。
* **仿写而非复制**：本 skill 的产出是"仿其句式、不抄其原句"的新文字。SKILL.md 内置「如何像土豆而不抄桥段」的防撞型纪律——保留压抑→爆发的振幅、宣言句、围观量度与感叹号节奏，但换人物、换场景、换冲突源。

## 效果示例

### 问：用土豆的文笔写——云岚宗大殿，退婚之时，萧炎当众撕破休书。

```
土豆文笔   ❯ 萧炎缓缓抬头，目光平静得没有一丝波澜。

              他伸出手，将那枚象征婚约的玉佩捏碎在掌心，
              碎玉落地，叮当作响，却比云岚宗那满殿的强者威压
              更让纳兰嫣然呼吸一滞。

              "三十年河东，三十年河西，莫欺少年穷！"

              大殿之上，所有人脸上的轻视，都在这一瞬间凝固。
              无数道目光，皆是错愕地望向那少年——方才还被当成
              废物看轻的少年，此刻竟敢在云岚宗，说出这样的话。

              萧炎转身，再不回头。心中有的不是今日的愤怒，
              而是三年前那个倾尽全力的少年，曾在灯下一遍遍试炼
              的影。他要让自己这些人，终有一日，不得不仰望。

              ——轰！
```

### 问：用土豆的文笔写——萧薰儿试探林家少年，林动体内沉睡的力量苏醒了一角。

```
土豆文笔   ❯ 那一缕劲风欺近身来，林动几乎是本能地一抬手。

              拳未到，丈许内的空气先是一颤，仿佛有什么蛰伏已久
              的东西，在这一刻睁开了眼。绫清竹眉心微蹙——她分明感觉到，
              这股力量，与眼前这个看门的林家少年，本不该有任何关系。

              "糟了……"

              她心头刚掠过这两个字，林动周身衣袍已是无风自鼓。

              轰！

              一道闷响，将林动逼退了七步。他不是被震退——
              是强行压下了那几乎要破体而出的力量，硬生生退开，
              不去伤她。绫清竹怔怔望着那少年，眼中第一次露出凝重。

              这林家，何时藏了这么一头……
              连她自己，都看不清的猛虎。

```

> 完整的实战记录（执行路径 + 逐条自评）在 [examples/](#仓库结构) 目录（规划中）。

这不是"给 AI 塞了几页爽点摘抄"。每段输出都在执行 SKILL.md 里可核验的技法：目标感账本先行、压抑→爆发闭环、围观量度量给读者看、权威解说揭底牌、宣言三连、感叹号节奏。它不复读土豆的原句，它用土豆的**结构与节奏工程**重写你的素材。

## 蒸馏了什么

### 6 大心智模型（镜片）

| 镜片            | 一句话                             | 应用                  |
| -------------- | -------------------------------- | ------------------- |
| **目标感引擎**      | 主角必吊一个贯穿到底的具象目标，缺则中后期散架    | 诊断长篇先问"主角欠读者一句什么账" |
| **压抑→爆发循环**   | 爽源于振幅：先让读者憋屈，再狠狠释放，反复循环     | 打脸前确保压抑到位，抑得越狠扬得越爽 |
| **换花样对抗疲劳**   | 读者快疲劳时插入新冲突/新地图/新敌人/新目标      | 一个副本写满即换，不恋战       |
| **可背诵的等级阶梯**  | 境界=名词阶梯+数字计量+能力飞跃的具象化        | 每境读者能否一句话讲出"他厉害在哪" |
| **借围观立高高**     | 极少直写主角强，靠全场目光/倒吸凉气/权威解说量度   | 写围观者的瞳孔和下巴，而非主角心理   |
| **情绪统一＞结构求新** | 一部小说的核心是情感；套路可重复，情绪必须真诚统一    | 先看爽点是否服务"少年热血励志"谱系  |

### 10 条决策启发式（快速判断）

每章一个「小目标」· 受辱必打脸（相邻章节闭环）· 角色开口即宣言 · 爽点三件套（感叹号+围观震惊+权威解说）· 新副本入场看清"地图读数见顶"· 坚持＞天赋 · 读者反馈可吸纳但不改主线 · 不换轨 · 晋级必给"可见的天地反馈"· 降级求稳。

### 8 类表达 DNA（写作时逐条对齐）

**超长逗号连缀长句 +"令得/让得/顿时/也是"因果链** · **拟声词独立成段（"轰！""唰！"）** · **省略号造哽咽（先哽咽后爆发）** · **围观视角词库（无数道目光/倒吸凉气/震撼/战栗）** · **权威解说揭底牌** · **宣言三连** · **时间程式（片刻后/旋即/下一霎那）** · **境界名词阶梯**。

### 诚实边界（最容易破功的地方）

* **目标感空转 = 傻白爽**：只用句式而缺"情绪统一/目标感"，会退化成被批"文笔平"的凑字模板——写爽文前先问情感内核。
* **领域不在场要声明**：现实/严肃文学/短篇精修/AI 伦理，他"不在场"，只按价值观推断并明确标注，不以亲口身份下结论。
* **需事实要核实**：涉及最新连载/设定/平台转会的动态信息，先研究、明写信息截止日期，绝不编造。
* **拒绝洗稿/撞型**：不加锁判断"人物+受辱+金手指"三重配置是否与某原桥段雷同，雷同即换一层，不逐句仿写。

### 内在矛盾（不是脸谱化的"爽文批发机"）

* **稳定更新第一 vs 我挺懒的**：他自述"一天更两章、坚持是最大天赋"，又自认"靠公司/豆嫂/压力制度补足"——纪律是补短板，不是天生自律。
* **情绪统一 vs 换皮自我抄袭**：他把被吐槽的套路亲自转成"验证有效的个人签名"（"抄自己犯法吗"），外界却批"换汤不换药"——本 skill 两者都保留，不替他圆谎。
* **玄幻顶流 vs 非首创清醒**："玄幻第一人""废柴流创始"与"穿越/升级并非其首创"并存，他更该被称作"集大成熟练者"。
